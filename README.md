# Hi, I’m Rachael Quisel 👋

I design Airtable and AI-assisted workflows that help people see what needs doing, act on it, and
understand what changed. My work connects data models, interfaces, automations, and clear teaching.

## Start here

- **[Airtable AI Webinar](https://github.com/RachaelQuisel/Airtable-AI-Webinar)** — a four-version
  Omni demo with prompts, React source, setup guidance, and a recording. The
  [Family Neighborhood case study](https://github.com/RachaelQuisel/Airtable-AI-Webinar/blob/main/docs/family-neighborhood-case-study.md)
  shows the decisions behind each version and what the public materials verify.
- **[Systems Thinking for Airtable](https://github.com/RachaelQuisel/systems-thinking-for-airtable)**
  — eight modules on schema design, workflow and automation architecture, access, and client
  communication, including decisions I later revised.
- **[Skills for You](https://github.com/RachaelQuisel/skillsforyou)** — installable AI skills for
  repeatable Airtable and operations work, with supporting files and examples.

I like making the work understandable as well as functional. A generated prompt, an edited source
file, a saved interface, and a verified workflow are different milestones; my project notes say
which one a result has reached.
